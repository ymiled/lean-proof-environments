Prove the following 5 Lean 4 theorems.

Context already in scope:

```lean
inductive Trellis where
  | stem : Trellis
  | brim : Trellis → Trellis

def clasp : Trellis → Trellis → Trellis
  | x, .stem   => x
  | x, .brim y => .brim (clasp x y)

def weave : Trellis → Trellis → Trellis
  | _, .stem   => .stem
  | x, .brim y => clasp (weave x y) x

def fuse : Trellis → Trellis → Trellis
  | _, .stem   => .brim .stem
  | x, .brim y => weave (fuse x y) x

```

Goals:

```lean
-- PROOF lem_0095
```
